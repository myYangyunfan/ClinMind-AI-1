## 0. 全局不变量（写内容前必须先满足）

### 0.1 数值口径

| 项 | 规则 | 出处 |
|---|---|---|
| 情绪量纲 | 引擎内部一律 0.0–1.0 浮点；UI 显示 `round(x*100)%` | 总纲 §2 |
| 最小变化粒度 | 0.005；小于该值不落库、不弹提示 | 总纲 §2 |
| 患者信任初值 | 0.40（参与判负） | 总纲 §1.3 |
| 患者焦虑初值 | 0.50（不判负，只驱动配合度） | 总纲 §1.3 |
| 家属焦虑初值 | 0.65（不判负，只驱动干扰事件） | 总纲 §1.3 |
| 时间项下限/上限 | 信任触底 0.15、焦虑触顶 0.85、家属焦虑触顶 0.85 | 总纲 §1.2 |
| 行为阈值 | 焦虑 ≥0.90 拒配合；信任 ≤0.10 持续 60 s 离院；信任 ≤0.05 且近 3 次交互全负面立即离院 | 总纲 §2.4 |

### 0.2 三档判定（全部 18 条文案共用）

| 档位 | 标签 | 判定式 | 选择优先级 |
|---|---|---|---|
| high | 信任高 | `patient_trust ≥ 0.70` | 最高 |
| mid | 信任中 | `0.30 ≤ patient_trust < 0.70` | 次之 |
| low | 信任低 | `patient_trust < 0.30` | 最低（兜底，永不为空） |

> 三档只看 `patient_trust`，不看焦虑。焦虑只改「配合度行为」（拒检查 / 回答缩成一句），不改「说哪一档话术」。这样 5 例 ×6 节点 ×3 档 = 90 条文案与焦虑维度解耦，可回归。

```
ticagrelor / 替格瑞洛
clopidogrel / 氯吡格雷
heparin / 肝素
alteplase / 阿替普酶 / rtpa / rt-pa

tenecteplase / 替奈普酶
bivalirudin / 比伐卢定
warfarin / 华法林

```

消费点：`physiology_engine.apply_medication()` 第 77 行 `is_lethal = any(keyword in normalized_name for keyword in config.LETHAL_MEDICATION_KEYWORDS)`；命中后 `trigger_iatrogenic_rupture()` 启动 **120 s** 致命心包填塞倒计时（`physiology_engine.py:78-86`）。

> ⚠ 该清单与 `config.py:190` 的注释「Contraindicated for Stanford Type A Aortic Dissection」是**夹层专用**的。病例 2–5 不是夹层，`physiology_engine.py:73-74` 已用 `if not self.high_risk_aortic: return self._apply_generic_medication(...)` 分流，因此病例 2–5 的「红线」是**内容层语义红线**（由 `prescription_rules.verdict = "RED_LINE"` 承载），不继承上述关键词表。这一点必须写进实现，见 §8 缺口 G-03。

### 0.4 检查别名兼容（决定 `lab_panels` 的命名）

`guardrail_engine.route_lab_or_imaging()` 靠中文别名命中，`lab_panels[].name` 与 `.alias` 必须至少命中一个，否则返回 `NOT_CONFIGURED` +「护栏拒绝编造检验数值」。已验证可命中的别名（`guardrail_engine.py:152-230`）：

- **18 导联心电图**：心电图 / ecg / 18导联 / 十二导联 / 12导联
- **床旁超声心动图**：超声 / 心包 / echo / pocus / 心脏彩超 / 床旁超声
- **心肌标志物**：肌钙蛋白 / ctni / 心肌酶 / tnt / ckmb / 心肌标志物
- **D-二聚体**：d-二聚体 / d-dimer / 二聚体
- **主动脉 CTA**：cta / 增强cta / 主动脉全长 / 大血管cta / 主动脉造影 / 主动脉cta
- **血常规**：血常规 / cbc / 白细胞 / 血红蛋白；**凝血四项**：凝血 / inr / aptt / pt / 纤维蛋白原

同理 `route_physical_exam()` 的关键字（`guardrail_engine.py:60-105`）决定了 `exam_options[].match_keywords` 的取值，见 §2.2 与 §1.3。

## 1. 六个新增字段的字段契约

### 1.1 通用约定

| 约定 | 规则 |
|---|---|
| 挂载位置 | 全部挂在病例 JSON 顶层，与 `case_id` 同级 |
| 命名风格 | 键名 `snake_case`；枚举值用 `UPPER_SNAKE` 字符串，禁数字码 |
| 时间单位 | 一律「虚拟秒」，字段名必须带 `_seconds` 后缀 |
| 语言 | 全部中文字段值为简体中文；`case_id` / `exam_id` / `panel_id` / `rule_id` 为 ASCII |
| 缺省 | 六字段全部**必填**；缺失即启动校验失败（总纲 §8 验收 10） |
| 禁写 | 禁 `"待补充"` / `"TBD"` / `"酌情"` / `"视情况"`；禁空字符串；禁 `null` |

### 1.2 `emotion_scripts`

| 属性 | 定义 |
|---|---|
| 类型 | `object` |
| 必填 | 是 |
| 键集合 | 固定 6 个节点 ID，顺序固定 |
| 值类型 | `object`，键固定为 `high` / `mid` / `low`，值为 `string` |
| 条数 | 6 × 3 = 18，一条不能少 |
| 单条长度 | 20–120 个汉字（短于此视为占位；长于此不利于 TTS/动画同步） |
| 禁写 | 禁出现诊断名（患者不知道自己是夹层）、禁出现具体药名剂量（患者不懂）、禁旁白（旁白走 `outcomes`） |

**6 个节点 ID（全 5 例统一，不得改名）**

| node_id | 中文名 | 触发时机 | 对应模块 |
|---|---|---|---|
| `E1_CONSULT` | 接诊初见 | 会话创建后首次渲染患者台词 | 问诊 |
| `E2_PAIN_DETAIL` | 问诊深入 | 首次命中任一 `inquiry_points[]` 要点 | 问诊 |
| `E3_PHYSICAL` | 体查配合 | 首次完成任一 `exam_options[]` | 体查 |
| `E4_WAIT_LAB` | 检查等待 | 首个 `lab_panels[]` 进入 TAT 等待 | 检验 |
| `E5_RX` | 处方处置 | 首次提交合法处方（`verdict ∈ {TARGET, SUPPORTIVE}`） | 处方 |
| `E6_PRE_OUTCOME` | 结局前夜 | 结局判定前最后一次交互 | 转归 |

### 1.3 `exam_options`（体查）

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `exam_id` | string | 是 | `PE_` 前缀 + 大写下划线，全病例内唯一 |
| `name` | string | 是 | 中文检查名；**必须能命中 `guardrail_engine.route_physical_exam` 关键字** |
| `match_keywords` | string[] | 是 | ≥3 个；首个必须是 `name` 的子串 |
| `duration_seconds` | integer | 是 | 虚拟秒，取值 ∈ {30, 60, 90, 180, 300} |
| `required` | boolean | 是 | `true` = 计入「体查 5 项」必做清单，缺失扣分 |
| `is_abnormal` | boolean | 是 | 本例是否有阳性所见 |
| `findings` | object | 是 | 固定两键：`normal` / `abnormal`，均为非空 string |
| `clinical_point` | string | 是 | 一句话说明「这一查为什么值 60 秒」 |
| `guard_note` | string | 否 | 与其他部位查体易混淆时的排除说明 |

```json
{
  "exam_id": "PE_BP_BILATERAL",
  "name": "双侧上肢血压对比测量",
  "match_keywords": ["双侧上肢血压", "双臂血压", "压差", "双上臂"],
  "duration_seconds": 60,
  "required": true,
  "is_abnormal": true,
  "findings": {
    "normal": "双侧上臂收缩压差 < 10 mmHg，对称。",
    "abnormal": "右上臂 195/115 mmHg，左上臂 162/98 mmHg，收缩压差 33 mmHg（>20 mmHg，强阳性）。右桡动脉洪大有力，左桡动脉显著减弱。"
  },
  "clinical_point": "60 秒拿到「双臂压差」这一条，比等 1500 秒的心肌酶早 24 分钟给出定性方向。",
  "guard_note": "提问中不得出现「瞳孔/下肢/足/腘/肺/呼吸音」，否则会命中其他查体分支。"

```

> **契约级约束**：`name` 与 `match_keywords` 的并集必须命中 `guardrail_engine.py:60-105` 的六组关键字之一；否则运行时返回「本病例未配置该项查体的确定性结果（防幻觉护栏拒绝编造查体所见）」，验收 8 直接挂。

|---|---|---|---|
| `panel_id` | string | 是 | `LAB_` / `IMG_` 前缀 + 大写下划线 |
| `name` | string | 是 | 中文名；**必须命中 `route_lab_or_imaging` 别名**，见 §0.4 |
| `alias` | string[] | 是 | ≥2 个，含至少一个纯小写英文别名 |
| `modality` | enum | 是 | `ECG` / `LAB` / `IMAGING` / `ULTRASOUND` |
| `tat_seconds` | integer | 是 | 虚拟秒；**必须与总纲 §3.4 同值**（见 §2.4 冲突表） |
| `is_key` | boolean | 是 | 是否属「检查 6 项」必开清单 |
| `is_gold_standard` | boolean | 是 | 每例恰好 1 个为 `true` |
| `is_trap` | boolean | 是 | 结果会诱导误诊的「陷阱项」 |
| `decision_window` | enum | 是 | `WITHIN_CLOCK`（恶化时钟内可回报）/ `BEYOND_CLOCK`（超出时钟，等它就是等死） |
| `result_text` | string | 是 | 具体数值，禁模糊 |
| `ref_range` | string | 是 | 参考区间；影像类填 `"—"` |
| `conclusion` | string | 是 | 报告结论一句话 |

### 1.5 `prescription_rules`（处方）

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `rule_id` | string | 是 | `RX_` 前缀 |
| `drug_name` | string | 是 | 处方下拉里的显示名（唯一） |
| `match_keywords` | string[] | 是 | ≥1；一级红线必须同时含中文名与 `config.py` 里的小写英文名 |
| `verdict` | enum | 是 | `TARGET` / `SUPPORTIVE` / `WARN_ONLY` / `RED_LINE` / `OFF_LIST` |
| `severity` | enum | 否 | 仅当 `verdict == "RED_LINE"` 有效；`LETHAL`（默认，即死）/ `HARMFUL`（加速病程、累计可致 D）。其余 verdict 省略此键 |
| `dose` | string | 是 | **具体数值 + 单位 + 给药节奏**，禁"适量" |
| `route` | string | 是 | 静脉泵入 / 静脉推注 / 口服 / 雾化 / 舌下 |
| `frequency` | string | 是 | 具体频次 |
| `target` | string | 是 | 达标阈值（如 `HR < 60 bpm`），无靶目标填 `"—"` |
| `prerequisite` | string | 否 | 前置条件；`WARN_ONLY` 必填 |
| `consequence_text` | string | 是 | 命中后的系统文案（红线须含「为什么致死」的机制） |
| `score_delta` | number | 是 | 对应 §2.3 事件项，如 `0.04` |

**`verdict` 语义**

| 值 | 含义 | 引擎动作 |
|---|---|---|
| `TARGET` | 正确靶向处置 | 加 `score_delta`，推进生理状态机 |
| `SUPPORTIVE` | 合理辅助处置 | 加 `score_delta`，不改主状态 |
| `WARN_ONLY` | 单用有害、联用合理 | 弹护士拦截话术，不判死；`prerequisite` 未满足时扣分 |
| `RED_LINE` | 一级红线（严重度见 `severity`） | `severity = LETHAL`（默认）：立即 `trigger_iatrogenic_rupture()` → 结局 D；`severity = HARMFUL`：护士拦截 + 扣分 + 恶化加速，累计 2 次进结局 D |
| `OFF_LIST` | 不在本案药品表 | 拒绝开具，不消耗虚拟时间 |

```json
{
  "rule_id": "RX_ESMOLOL",
  "drug_name": "盐酸艾司洛尔注射液",
  "match_keywords": ["艾司洛尔", "esmolol"],
  "verdict": "TARGET",
  "dose": "负荷 0.5 mg/kg 静推 1 min（约 35 mg），随后 50-200 µg/kg/min 静脉泵入",
  "route": "静脉泵入",
  "frequency": "持续泵入，按心率滴定",
  "target": "HR < 60 bpm",
  "consequence_text": "β1 受体阻滞降低 dP/dt 与心率，主动脉壁剪切应力下降。达标后疼痛评分随之下降。",
  "score_delta": 0.04
}
```

### 1.8 六个字段之外的 12 项必填键位（启动校验用）

总纲 §4.2 的 12 项落在 JSON 上的键位如下，校验器按此表逐项核，缺任一项须报出缺失字段名（验收 10）：

| # | 总纲 §4.2 条目 | JSON 键位 |
|---|---|---|
| ① | 主诉（一句含时间） | `chief_complaint` |
| ② | 现病史 5 要素 | `present_illness{onset,character,radiation,trigger,relief}` |
| ③ | 既往史 + 用药史 | `patient_profile.past_history` + `patient_profile.medication_history[]` |
| ④ | 危险因素 | `risk_factors[]`（≥3） |
| ⑤ | 阳性体征 3 + 关键阴性 2 | `key_positives[]`（=3）+ `key_negatives[]`（=2） |
| ⑥ | 问诊要点 8 个 | `inquiry_points[]`（=8） |
| ⑦ | 体查 5 项 | `exam_options[]` 中 `required == true` 的条目（=5） |
| ⑧ | 检查 6 项含 TAT 与陷阱 | `lab_panels[]` 中 `is_key == true`（=6），且至少 1 项 `is_trap` |
| ⑨ | 金标准 1 项 | `lab_panels[]` 中 `is_gold_standard == true`（=1） |
| ⑩ | 鉴别 3 条各带「为什么不是」 | `differentials[]`（=3，每条含 `why_not`） |
| ⑪ | 红线 2 条 | `prescription_rules[]` 中 `verdict == "RED_LINE"`（=2），且其中 ≥1 条 `severity` 取默认值 `LETHAL` |
| ⑫ | 知识点 5 条 | `knowledge_card.items[]`（=5） |

## 2. 病例 1：孙建国 · Stanford A 型主动脉夹层

> 全部临床事实取自 `aic_mech/app/data/case_chest_pain.json`，本规格不改动任何数值。

### 2.1 病例 1 的 12 项必填

| 时刻 | 累计虚拟秒 | 事件 | 生理阶段（总纲 §1.2） |

| t0 | 0 | 接诊、吸氧、心电监护、双通道（N4） | 稳定 0–180 s |
| t1 | 60 | **P1 双臂血压 → 压差 33 mmHg**（第 1 分钟定性） | 稳定 |
| t2 | 120 | P2 心脏听诊 → 新发舒张期杂音 | 稳定 |

| 时刻(s) | 事件 | 恶化时钟（0–240 稳定 / 240–600 加重 / 600–960 危象 / 960–1200 终末） |
|---|---|---|

| 900 | **NT-proBNP 4860 回报（赶得上，1200 s 内）** | 危象期边缘 |
| 1500 | 肌钙蛋白回报（**晚于 1200 s 终末**，若只等它，患者已死） | — |

| 600 | 头颅 CT + 颈动脉超声回报 | 反复跌倒期前段 |
| 900 | 电解质（K 3.2、Na 132）+ 血常规回报 | 反复跌倒期 |
| 1800 | **MRI-DWI 回报**：阴性 | **恰好到达分水岭梗死窗口尽头** |

> 关键结论：**MRI-DWI 1800 s 刚好压着 1800 s 的恶化时钟，赌不起。** 必须在第 180 秒用「卧立位血压」完成定性——这是本例唯一的「300 秒级」决定性检查。等 MRI 而不先纠正低血压，等于让大脑在最低灌注压上多捱 27 分钟。
