## 2. 引擎模块 `aic_mech/app/core/emotion_engine.py`（新建）

```python
@dataclass
class EmotionState:
    patient_trust: float = 0.40
    patient_anxiety: float = 0.50
    family_anxiety: float = 0.65

class EmotionEngine:
    def __init__(self, state: EmotionState   None = None) -> None: ...
    def tick(self, dt: float) -> dict[str, float]:      # 返回本次实际变化量，供日志
    def apply_event(self, code: str, ctx: dict   None = None) -> dict[str, float]: ...
    def snapshot(self) -> dict: ...
    def dump(self) -> dict: ...                          # 持久化
    @classmethod
    def load(cls, data: dict) -> "EmotionEngine": ...
```

`snapshot()` 固定键：

```json
{
  "patient_trust": 0.40,
  "patient_anxiety": 0.50,
  "family_anxiety": 0.65,
  "trust_trend": 0,
  "anxiety_trend": 1,
  "refuse": false,
  "leave_reason": null,
  "refused": false
}
```

`trust_trend` / `anxiety_trend` 取值 `-1   0   1`（30 秒窗口内的净变化方向）。

事件码（`apply_event(code)`，delta 与冷却照 `02` §2.3）：

  code   信任   患者焦虑   冷却  
 --- --- --- --- 
  `RELEVANT_QUESTION`   +0.03   −0.02   同要点不重复  
  `REPEAT_QUESTION`   −0.02   +0.03   —  
  `IRRELEVANT_QUESTION`   −0.03   +0.02   —  
  `COMFORT`   +0.05   −0.08   60 s，冷却内减半  
  `EXPLAIN_EXAM`   +0.04   −0.05   每次检查 1 次  
  `SKIP_ALLERGY`   −0.10   +0.05   —  
  `EXAM_CORRECT`   +0.02   −0.02   每项 1 次  
  `CORRECT_TREATMENT`   +0.04   −0.06   —  
  `RED_LINE_MED`   0   0   由 physiology 处理  

判定顺序（`tick` 内）：立即离院线 → 持续离院线 → 拒绝配合标志。`leave_reason` 取值 `"leave_immediate"   "leave_sustained"   null`。

## 3. 会话层（`app/core/session_manager.py`）

- `SessionState` 新增：`emotion: EmotionEngine`、`emotion_accum: float = 0.0`、`terminal_reason: str   None = None`。`is_finished` 保留但**降为派生值**（`terminal_reason is not None`）。
- `tick(dt)` 内：生理照旧；情绪按 5 秒累加器结算，返回 snapshot 可选。
- `persist()` 的 keys 列表必须新增 `emotion`（调 `emotion.dump()`）与 `terminal_reason`；`load` 侧兼容老数据（无字段时按初始值建）。
- 死亡（S6）时置 `terminal_reason="death"`。

## 4. API 输出（`app/api/routes_case.py`、`app/api/websocket_feed.py`、`app/models/schemas.py`）

会话工作区响应与 WS 帧新增字段（**只增不改，旧字段保留**）：

```
patient_anxiety: float      # 0~1
family_anxiety: float       # 0~1，兼容旧 agent_anxiety（同值保留）
trust_trend: int
anxiety_trend: int
refuse: bool
terminal_reason: str null
```

`routes_action.py`：每个动作执行后调 `session.emotion.apply_event(code, ctx)`，动作类型到事件码的映射：

  action_type   code  
 --- --- 
  问诊（切题/重复/无关由 agent_engine 判定后给出 `question_kind`）   `RELEVANT_QUESTION` / `REPEAT_QUESTION` / `IRRELEVANT_QUESTION`  
  体查   `EXAM_CORRECT`  
  安抚（自由文字命中安抚语义）   `COMFORT`  
  解释检查目的   `EXPLAIN_EXAM`  
  用药（正确处置）   `CORRECT_TREATMENT`  
  用药（红线）   `RED_LINE_MED`  

拿不到判定时**不得瞎猜**：`question_kind` 缺省按 `RELEVANT_QUESTION` 处理，并在响应里回 `emotion_applied: false`。
